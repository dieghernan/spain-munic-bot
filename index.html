About the project

Follow @spainmunic

This project generated maps of buildings in Spanish municipalities, inspired by Dominic Royé’s urban-growth visualizations. Automated posting is currently disabled. The last public output record is dated May 17, 2022.

R packages

Core packages used in the project are:

  • CatastRo for the buildings.
  • mapSpain for the location of the municipalities.
  • ggplot2 for plotting.
  • rtweet for posting.

Other packages include sf, dplyr and supporting tools.

The project uses renv to record its R package dependencies. External data services and publishing APIs may have changed since the maps were generated.

Original execution workflow

The original entry point is shown below. It invokes the map-generation and Twitter publishing code. Review its configuration, dependencies and API credentials before running it; it is not a preview-only command.

    $ Rscript R/trigger.R

This will trigger R/01_create_map.R and compose the tweet.
