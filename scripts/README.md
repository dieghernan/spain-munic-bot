# Social images

`social-card.html` composes the site's existing Málaga building map with the
Libre Franklin typeface and the black, white and blue palette from Chulapa's
`twitter-lights-out` skin. The source map is `assets/img/sample.png`; its
construction-period colors are preserved.

Serve the repository root, open `scripts/social-card.html` and capture a JPEG
at a viewport of 1200 × 630 for `assets/img/social-preview.jpg` and 1280 × 640
for `assets/img/github-preview.jpg`. Wait for the local font and map to load
before capturing. Use 100% browser zoom.

Map data: Dirección General del Catastro. Urban-growth visualization inspired
by Dominic Royé. Libre Franklin is bundled with its OFL license.
